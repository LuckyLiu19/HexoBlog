常见问题

  • 命令提示找不到 hexo：确认 Node.js 和 Hexo CLI 已安装，并重新打开终端后再试。
  • 部署后页面仍是 404：检查仓库名、deploy.repo 和 GitHub Pages 发布分支是否正确，并等待构建完成。
  • 项目仓库部署后样式或图片丢失：确认 _config.yml 中的 root 设置为 /仓库名/。
  • 本地页面正常但线上未更新：重新执行 hexo clean、hexo generate 和 hexo deploy，并检查部署命令是否报错。

结语
